# 几何与动线验收

## 建模前写出正例与反例

将公共区、处理区、候机区、到达廊道、商店和室外定义为空间节点，门与扶梯为带方向、标高和条件的连接。手续顺序依当前建筑资料确定，不假设所有机场一致。

| 示例合同 | 正例 | 反例 |
|---|---|---|
| 国内出发 | 公共区经安检到国内候机 | 绕过安检到候机 |
| 国际出发（本次 T3） | 边检后安检，再到国际候机 | 跳过一关或顺序颠倒 |
| 到达 | 对应廊道经正确下行扶梯到到达层 | 错落另一控制区或穿中间楼板 |
| 公共侧商店 | 未安检区可进入店内 | 穿店进入已安检区 |

机场公共值机区并不必然需要国内国际完全分隔；个案分隔要求来自证据或用户确认。不能把一张手绘图的推断当成通用机场规则。

## 从实际 GLB 验证

从本次成功导出的 GLB 提取楼板与障碍网格，按楼层和多个身体高度切片，或建立导航网格/胶囊碰撞。墙、玻璃、门框、栏杆、立柱、店顶和扶梯都纳入；可见性开关、透明材质和手画箭头不改变几何通行性。

以门洞宽度选择网格分辨率，按约定人体半径扩张障碍，记录单位、身高、半径和覆盖范围。本次 T3 的 0.25 m 网格、0.22 m 半径、额外 0.68 m 宽出口采样只是建模检查参数，不是无障碍或建筑法规认证。

同时检查脚下支持与身体无障碍。禁止对角穿角；端点落在障碍内应报告，不能随意吸附到墙另一侧让测试通过。跨层路线必须使用真实设备端点和方向，不能用穿楼板直线连接。

## 受控路径检查

画一条合法路线只能证明有一种走法，不能证明没有绕行。检查至少包括：

1. 正常状态下，所有应开放的入口、设备出口、取物区和汇流路线可达。
2. 封闭安检通道，公共区不能到达候机区。
3. 若边检是前置步骤，封闭边检后不能抵达其后的安检入口或候机区。
4. 隔离两侧分别只能到达获准的扶梯、廊道和处理区；必要时封住其他检查口排除逆向绕行。
5. 对公共侧商店：公共区到店内可达；安检封闭时店内到候机不可达；正常时经合法安检可到候机。

需要顺序、单向门和反向回流验证时使用状态图。无向可达性不能证明方向和手续次序；静态模型也不能模拟不存在的门禁或工作人员。

## 几何检查

- 楼层：全部侧墙、楼板洞口、跨层挑空、门洞和门槛；上下层分别检查。
- 扶梯：入口/出口接地、实际方向和跨层、全段净空、栏杆不横断落点。
- 设施：各自多边形匹配参考；三角商店的店顶和墙共享轮廓；门洞无残余玻璃、踢脚和压条。
- 隔离：背墙、侧墙、玻璃端部和商店连接闭合，删除旧隔板不形成旁路。
- 穿模：包围盒筛选候选，再用面片相交或实体检测确认；柱接梁是正常接触，柱占门、墙穿店、牌子穿板才是缺陷。
- 标牌：实体支撑、正反面文字、斜面安装角度、楼板净空。

设与缺陷直接相关的断言，例如旧斜隔板残留为零、店顶轮廓匹配、指定侧无门、入口净宽、柱顶到下表面的距离。不能只检查新增对象，而忽略原来同位置的旧实体。

## 视觉复核与回归

用用户截图的同角度复核，并补俯视、剖面和入口反面。检查开/关屋顶两种情况；截图被柱、顶或面板挡住就另拍，不把遮挡当作通过。外观比较先对齐镜头，不通过换角度隐藏比例差异。

低细节阶段就跑拓扑测试，增加装修后再跑受影响路径。测试失败先查真实通道；新增设施确实改变路线时可更新合法路线，但保留独立禁止绕行检查，不能删掉失败用例来“通过”。

每份报告绑定模型 SHA-256、检查范围和执行结果。构建失败停止依赖步骤；不能继续测试旧 GLB 并宣布新模型合格。检查后又改了模型，旧结果失效。截图、图形合同和网格检查互补，任何一项不单独等于还原完成。
