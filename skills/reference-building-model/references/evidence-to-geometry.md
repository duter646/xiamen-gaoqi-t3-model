# 从网上资料到可建模结构

本流程针对“找到了图，却错误解释空间”的失效。不要要求模型仅凭一次看图就直接生成可靠建筑。把检索、观察、解释、坐标转换、反证分开，使每一步可检查；这能减少未经验证的假设，不能消除模型视觉理解能力的限制。

## 1. 用问题驱动检索

先建立“未知问题—需要的证据”表，而不是泛搜建筑名后收集一批漂亮图片。

| 未知问题 | 优先检索的资料 | 不能据此推出的结论 |
|---|---|---|
| 共有几层、扶梯跨哪层 | 全部楼层图、剖面、连续行走影像 | 从一个扶梯入口推断下端位置 |
| 梁、屋面还是檐口 | 相近部位的端面、内景、外景 | 把同向线条全部归为屋面 |
| 商店形状及入口朝向 | 平面轮廓、两侧近景、公共区导向图 | 图标处就是门、常见商店必然是矩形 |
| 一段是楼板还是挑空 | 上下层对应图、俯视内景、栏杆与楼板边缘 | 图纸灰色一定有楼板 |
| 隔离线如何连接 | 检查区全景、两端接口、门面及通行说明 | 一条合法箭头意味着不存在其他通路 |

检索词组合建筑全名/别名、楼层或构件、方向、时期；必要时使用当地语言和英文。优先寻找原始楼层图、建筑设计资料与高分辨率实拍；官方导览图适合确认标识与流程，但仍可能简化真实形状。游记或视频可补充连续空间，不能因来源非官方直接忽略，也不能当作精确尺寸图。

每轮检索要回答一个具体疑点，并记录结果：解决、缩小到几种解释、仍未知。重复搜同类视角仍无法分辨时，换证据类型或找反侧/下层，不继续堆积同样的远景。确实无法解决则记录缺口及其影响；关键分支向用户展示材料和备选解释，避免让用户重新独自查资料。

## 2. 逐图观察，不先套结论

对原图做有坐标的标注层，保留原图不覆盖。可用矢量标注或图像查看工具放大、裁剪查看；标注不能生成不存在的细节，AI 补全图不能成为还原证据。若工具对图像编辑有特定要求，遵守其要求。

每张图记录：

- 建筑身份、日期或未知日期、楼层、视线朝向及判断锚点。
- 能直接看见的边缘、开口、落点、梁柱连接、遮挡关系和重复构件数量。
- 原始像素坐标或局部标注区域；缩放、裁剪与原图的变换。
- 哪些是看见的事实，哪些只是解释，哪些完全不可见。

例如，“有三条水平线”是观察；“有三层楼板”是解释。先追踪线条到端部，看它们连接窗带、梁、店顶还是楼板。阴影边缘、反射、玻璃竖梃和家具顶面不能自动识别为隔墙。不能把被遮住的入口登记成“无入口”。

## 3. 跨图建立同一对象的对应

用稳定锚点匹配：编号门/登机口、柱网、屋脊、扶梯两端、特征窗、转角。至少记录足够锚点来区分镜像、反向视角和重复开间误配。

建立“对象 ID → 图 A 标注 → 图 B 标注 → 楼层图区域”的对应表。图纸展示层的平移或旋转先消除，再比较跨层位置。内外景不能各建一套互不相干的结构；同一根梁在剖面、内景和外景中的连接必须一致。

单张透视图只能约束可见投影，不能恢复任意三维尺度。仅对同一平面使用单应变换；不同深度的对象不能一起拉正后量距。导览图若无统一比例，用它定邻接关系，度量尺寸另找锚点，不把拟合矩阵当成实测精度。

## 4. 保留候选解释，主动寻找反证

对影响整体结构的疑点列少量可区分的解释，每个解释写：支持观察、冲突观察、能区分它们的下一张图。不能因为某个解释容易用代码生成就选它。

例：某条斜线可能是外梁、内撑或屋面边。若解释为第二套屋顶，则应能在端面看见独立面厚与连接；内景只见直杆三角支撑，则“内部全是弧梁”受到反证。连续行走照片若显示某商店仅有公共侧门，则受控侧开口的假设不成立。

高影响结论优先用不同视角或不同证据类型交叉支持；同一张照片被多网站转载不是多份独立证据。没有额外来源时降低结论强度，不能编造置信百分比或硬凑来源数。

## 5. 先产出结构解释包，再写生成器

最小解释包应包含以下可检查内容，文件形式按项目选择，不必复制成重复文档：

1. 原图标注：直接观察与对象对应。
2. 统一平面：各层外轮廓、楼板/挑空、设施多边形、门和扶梯端点，标明坐标方向。
3. 关键剖面：楼层高度、跨层洞口、屋面/梁/内撑及柱顶连接。
4. 区域边界：公共/受控侧、开口权限、允许和禁止的通路。
5. 决策台账：结论、证据 ID、冲突、参数范围、未知项及采用原因。

关键参数应能反查来源，例如“三角店面斜边来自标注 A，门朝向由照片 B 确认”。缺少来源的尺寸明确为估计，设施形状和连接关系不能因此随意改变。解释包是后续几何的输入，不能等模型做完再反向编造证据。

## 6. 用投影检验解释，而不只检查自洽

从解释包生成低细节模型，对齐参考相机后投影叠加：检查轮廓、开间计数、台阶转角、扶梯落点、挑空边界和设施占地。保留误差和不匹配标注；不要调整多个相机参数来掩盖几何错误。

有额外视角时，用未参与拟合的照片验证；资料很少时至少留出其他锚点，并说明证据独立性有限。如果同一模型无法同时解释不同视角，回到结构假设或年代/身份核对，而不是继续增加贴图。

之后再做网格通路检查。它能证明模型内的关系，却不能证明这种关系符合现实。两项均有依据后才进入细化阶段；当观测不足以达到目标精度时，明确能还原的范围与尚缺资料，不以质量检查脚本代替资料理解。
