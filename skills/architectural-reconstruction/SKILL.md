# 证据驱动的建筑复原

目标是得到能说明“为什么这样建”、能复查、没有明显几何缺陷的建筑模型。不要从少量照片或既有建筑印象直接生成完整结构。每个重要形状、尺寸和连接都应来自证据，或明确标为估计。

## 开始前

确认建筑身份、目标年代或改造状态、建模范围、精度、单位、坐标方向、输出格式和使用场景。用户已决定的内容直接沿用；会显著改变范围或成果形态的未决事项再向用户确认。

建立以下工作文件，格式可按项目选择：

- **资料索引**：来源、日期、视角、覆盖对象、可信度和许可。
- **证据台账**：对象 ID、直接观察、解释、参数、来源 ID、冲突和未知项。
- **构件清单**：预期存在的楼层、立面、屋面、墙、洞口、柱梁、交通设施及重要固定设施。
- **验收报告**：资料覆盖、投影比对、构件完整性、穿模与连接检查及未解决项。

需要系统检索时读取 [资料收集](references/research.md)；把图像和图纸转成几何时读取 [证据到几何](references/geometry.md)；导出前读取 [质量检查](references/qa.md)。

## 工作关卡

### 1. 先证明资料覆盖足够

按建筑组成列覆盖矩阵，而不是按下载图片数量判断完成。至少核对总体形态、每个可见立面、屋面、各楼层、关键剖面、垂直交通、主要结构、门窗开口和目标范围内的室内空间。复杂或容易误读的部位需要互补视角或不同类型的证据。

实际打开原图并放大检查。搜索结果摘要、缩略图、文件名和相似建筑只能用于寻找线索，不能直接成为几何依据。每轮检索要解决一个明确疑点；同类图片不再提供新信息时，改找平面、剖面、反侧照片、连续视频或测量锚点。

**通过条件：**覆盖矩阵没有未说明的关键空白；来源冲突已解决或保留为明确候选；目标精度超过现有证据能力时，已缩小范围或向用户说明缺口。资料不足时不得凭感觉细化相关部位。

### 2. 把观察和解释分开

逐图记录可直接看到的轮廓、数量、连接、遮挡和相对位置，再写空间解释。不要把阴影当墙、把导览图底色当楼板、把外部梁当屋面，也不要把被遮挡的部分登记为不存在。

为重要对象分配稳定 ID，使同一根柱、墙、屋脊或开口能跨照片、平面和剖面对照。每个关键参数必须能反查证据；看不见或无法测定的尺寸记录为范围或未知值。

**通过条件：**证据台账能回答每个重要对象的来源、确定程度和采用理由；没有来源的细节不会伪装成已知事实。

### 3. 建立统一空间骨架

先统一坐标、比例和层高，制作平面、立面与关键剖面。记录各层外轮廓、楼板和挑空、墙和门洞、柱梁连接、屋面分层、楼梯/扶梯/电梯两端及固定设施占地。相似构件可复用零件，不能未经核对就复用位置、尺寸或轮廓。

先做低细节模型，只包含影响空间和外形的实体。用与参考图匹配的相机生成叠图，同时从未参与拟合的视角复核。若一个模型不能同时解释平面、剖面和多张照片，回到结构解释，不用装饰遮掩。

**通过条件：**全部目标楼层和外壳已出现；轮廓、开间数、层高、屋脊、挑空和跨层连接能与证据对应；高影响未知项仍保持可调整。

### 4. 在已验证骨架上增加细节

细节按“外轮廓与结构连接 → 门窗与固定设施 → 标牌与材质 → 小型陈设”的顺序加入。墙、顶、踢脚、玻璃和门洞应由同一轮廓数据生成，避免相邻构件各自猜测后互相穿插。

每批新增对象都更新构件清单和证据台账，并立即复查受影响的空间。用户指出错误时修正源轮廓或参数并清除旧实体，不叠加一层遮挡补丁。

### 5. 强制执行完整性和几何检查

按 [质量检查](references/qa.md) 检查，而不是只从漂亮的鸟瞰角度观看。至少包括：

- 构件清单与模型对象逐项对应，发现漏层、漏墙、漏屋面、漏门和漏连接；
- 包围盒筛选后做实际面片或实体相交确认，发现墙穿设施、柱占门、标牌穿楼板等穿模；
- 检查支撑关系和端点距离，发现浮空柱、栏杆、屋面、招牌和扶梯；
- 用逐层平面切片、关键剖面、每侧立面、室内近景和反面视角检查薄壳缺面及错误开口；
- 有通行要求时，从实际导出模型验证可达与禁止绕行，不能用手画路线代替。

构建失败、产物时间或哈希未更新时停止后续验收。修正后重新运行相关检查，不能删除失败用例或只调整截图角度。

**通过条件：**所有目标构件有可见或程序化检查记录；高严重度穿模、浮空、漏面和错误连通均已解决；剩余局限明确列出并与证据能力一致。

### 6. 交付一致的成果

从正式入口加载最终产物，检查模型、纹理、页面和下载链接。记录最终文件哈希及对应的验收报告；需要时运行 `python scripts/verify_delivery.py <验收清单.json>` 检查文件是否与验收时一致。

最终报告说明依据、完成范围、实际执行的检查和未覆盖内容。不要使用“完全一致”“零穿模”等超出证据和检查范围的表述。

## 不可接受的捷径

- 资料尚未覆盖关键结构就按常见建筑样式补齐。
- 找到资料但不逐张查看，在建模时依靠记忆或印象。
- 用一张透视图推断不可见的完整平面或精确尺寸。
- 将重复设施全部复制成同一占地而不核对差异。
- 只检查新增对象，不检查旧实体是否仍留在同一位置。
- 只做视觉截图，不检查背面、切片、碰撞、支撑和构件缺失。
